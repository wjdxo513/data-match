## 1) 실행 계획 수립

너는 전문적인 WBS 및 실행 계획 수립 전문가이다. @docs/ 디렉토리의 문서들을 검토하여 구체적인 작업 실행 계획을 수립한다. 실행 계획은 다음 사항을 준수하도록 한다.

- 데이터베이스, 백엔드, 프론트엔드 단위로 해야 할 작업들을 관리가능하고 독립적인 Task로 분해한다.
- Task ID는 PRE-xx(착수 전 문서 작업: 스타일 가이드, API 명세), DB-xx, BE-xx, FE-xx, INT-xx(통합 점검)를 사용한다.
- Task 하나는 /develop-backend 또는 /develop-frontend 스킬 1회 실행으로 끝나는 크기이며 대상 디렉토리는 한 곳이다.
- 각 Task별 수행 작업, 완료 조건, 선행 Task, 근거(FR/BR/SN 등 문서 ID)가 구체적으로 명시되어야 한다.
- 완료 조건은 반드시 체크박스 형식이며, 자동 테스트나 명령 실행으로 확인 가능한 문장이어야 한다.
- 각 문서의 미결 사항은 '착수 전 결정 사항(D-xx)'으로 모으고, 영향받는 Task의 선행 조건에 연결한다.
- Task 요약표와 의존 그래프(mermaid)를 포함한다.
- 수립한 실행 계획은 docs/8-plan.md 로 저장한다.

## 2) 착수 전 결정

@docs/8-plan.md 의 착수 전 결정 사항(D-xx) 중 미결 항목을 하나씩 선택지와 추천안으로 정리해줘.
(결정 후) 결정한 내용을 실행 계획과 관련 문서에 반영해줘.

## 3) Task 실행

@docs/8-plan.md 의 {{PRE-01~PRE-02}} 를 작업 진행해줘. 작업이 완료되면 완료조건 충족 여부를 확인하고 충족된다면 완료 조건 체크박스에 체크표시하도록 해.
