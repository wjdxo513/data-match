# 개발 중 자주 쓰는 프롬프트 모음 (필요한 것만 골라 사용)

## 문서 정합성
docs 디렉토리의 문서들을 비교검토하여 불일치한 부분이 있다면 업데이트해줘.

현재 코드와 @docs/ 문서를 대조해서 문서가 구현과 다른 부분을 찾아 문서를 코드에 맞게 갱신해줘. 각 문서의 버전 이력·변경 이력도 기록해줘.

## API
현재 백엔드 API의 상태를 반영해 @backend/swagger.yaml 을 업데이트하고 Swagger UI가 개발환경에서만 나타나도록 코드를 적용해줘.

백엔드 API에 Health Check Endpoint가 있는지 확인하고, 없으면 DB 연결 상태를 포함해 추가해줘.

사용자 시나리오를 기반으로 백엔드 API에 대한 테스트를 curl 명령어를 이용해서 수행해줘.

## 설정·보안
Cross Origin 문제를 해결하기 위해 이 프로젝트에서는 Proxy 방식, CORS 방식 중 어떤 방식을 적용하고 있어?

CORS 오리진을 환경변수로 설정하도록 업데이트해줘.

security-auditor 서브에이전트로 현재 코드의 보안 점검을 수행하고 심각도별로 발견사항을 정리해줘.

## 통합 테스트 (E2E)
현재 백엔드와 프론트엔드가 모두 개발서버로 실행중이야. playwright-mcp를 이용해 @docs/3-user-scenario.md 를 참조해 통합테스트를 수행해줘. 테스트 결과는 test/e2e 디렉토리에 저장해. 주요 화면, 엣지케이스에 대해 스크린 캡처를 수행하고 리포트에 포함시켜줘.
